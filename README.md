# AI-Travel-Itinerary-Planner-with-Kubernetes-GCP-and-ELK-Stack
An AI-powered travel itinerary planner web app uses LLMs and real-time search to generate personalized day-by-day itineraries based on user preferences, destinations, and travel style, showcasing an end-to-end LLMOps pipeline.
